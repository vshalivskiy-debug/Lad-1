# Лабораторна робота №1

## Тема
Ознайомлення з візуальним середовищем Visual C#. Компіляція та запуск програми на виконання.

## Мета роботи
Ознайомитися з середовищем розробки Microsoft Visual Studio, навчитися створювати проєкти мовою C#, виконувати компіляцію та запуск програми.

## Завдання
Створити програму мовою C# для обчислення математичного виразу відповідно до заданого варіанта.

## Виконання роботи
У середовищі Microsoft Visual Studio було створено програму мовою C#.

У програмі:
- задано початкові значення змінних;
- реалізовано математичний вираз відповідно до варіанта;
- виконано обчислення результату;
- результат виведено на екран;
- проведено компіляцію та запуск програми.

## Використані технології
- C#
- Microsoft Visual Studio
- .NET
- Git
- GitHub

## Висновок
Під час виконання лабораторної роботи №1 було опрацьовано основні можливості середовища Microsoft Visual Studio. Створено та запущено програму мовою C# для обчислення математичного виразу. Отримано практичні навички створення, компіляції та запуску програм.
